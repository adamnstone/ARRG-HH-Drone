Supplemental hardware-rate compatibility review

This run uses all 100 distinct hash-verified Hugging Face source clips cached for
Rachel's historical benchmark. Each source is a 0.5-second waveform at 16 kHz.
scipy.signal.resample_poly upsamples each clip by 3 to the 48 kHz analysis rate.
Upsampling introduces no native 48 kHz source information: source audio remains
limited to the original 16 kHz recording bandwidth.

The protocol tests one seeded randomized azimuth per clip at elevations 0, 30,
60, and 80 degrees, plus the 90-degree zenith case, at SNR 30, 20, 10, and 0 dB.
This yields 2,000 calls, versus 13,200 calls in the primary 16 kHz protocol with
eight azimuths per clip. It supplements the primary benchmark and verifies that
the estimator runs at the hardware sample rate; it is not the same sweep.

SNR is set using whole-waveform power while independent white noise is spread
across the analysis-rate Nyquist bandwidth. At the same nominal SNR the 16 and
48 kHz protocols therefore have different in-band noise power. Comparing their
numeric accuracy cannot isolate a causal sample-rate advantage.

These are mono recordings with simulated synchronized four-microphone delays
and added independent white noise, not actual four-channel hardware recordings,
reverberation, or diffuse-noise validation. Existing source recording noise is
propagated coherently with the source. Repeated scenarios are not independent
recordings. The confidence >= 0.2 gate is existing and not hardware calibrated;
withheld directions must not be counted as accepted successes.

This review reruns the estimator after its ambiguity and confidence checks were
strengthened. In these 2,000 cases, the only observed output change relative to
results_hf_four_mic_48k is stricter confidence: all raw vectors, their 3D errors,
their defined/undefined status, and ambiguity counts are identical. The review
accepts 1,523 estimates versus 1,542 previously; all 1,523 accepted estimates are
within 15 degrees. Nineteen additional accurate estimates are now withheld.
This benchmark alone does not establish how the ambiguity fix changes other
inputs, nor does it calibrate confidence for hardware use.

Coverage audit passed: 100 clips, 20 scenarios per clip, 100 trials in each of
20 elevation/SNR conditions, and 2,000 trials total. The same one raw error
exceeded 15 degrees (23.074 degrees, clip 69, 80-degree elevation, 0 dB SNR);
it remained withheld by confidence. Numeric outputs were not edited. The
per-trial comparison is recorded in comparison_to_previous.json.
